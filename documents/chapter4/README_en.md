# LLM Mathematical Reasoning
This project provides code that enables large language models (LLMs) to learn mathematical reasoning. The main technique is Supervised Fine-Tuning (SFT), which lets the model learn from responses generated by DeepSeek-R1 and acquire complex mathematical reasoning skills (such as reflection and verification).
Based on the [DeepMath-103K](https://huggingface.co/datasets/zwhe99/DeepMath-103K) dataset and the [Qwen/Qwen2.5-Math-1.5B](https://huggingface.co/Qwen/Qwen2.5-Math-1.5B) model, this experiment guides readers through a first attempt at the full data distillation pipeline for mathematical tasks.

## Experiment Objectives
- Understand the cleaning and preprocessing of math-related datasets
- Understand the basic methods for fine-tuning large models
- Understand the basic methods for inference with large models
- Understand the basic methods for evaluating a model's mathematical ability

## Environment Requirements

- Python 3.8+
- PyTorch
- Transformers
- Datasets
- vllm
- A GPU with at least 40GB of memory

## Experiment Documentation

1. Open the Jupyter notebook:
```bash
jupyter notebook sft_math.ipynb
```

2. The notebook contains several main parts:
   - Dataset download and preprocessing
   - Model loading and training
   - Model generation and evaluation

3. For specific operations and instructions, please refer to the notebook.

## Output Files

The training process produces checkpoint files, and the generation results are saved after generation is complete.

## Notes

- Models and data need to be loaded from Hugging Face. In mainland China, you can download them through the mirror at https://hf-mirror.com.
- Make sure you have enough disk space to store the original model files, data files, and the trained checkpoints (please reserve at least 50GB).
- A GPU with at least 40GB of memory is required.
